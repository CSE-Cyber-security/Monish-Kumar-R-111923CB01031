
Week 2 - Factorial of a Number

Description
This Python program calculates the factorial of a given number
using a for loop.

Requirements
- Python 3

How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

   python factorial.py

 Sample Input
5

 Sample Output
Enter a number: 5
Factorial of 5 = 120

 Concepts Used
- Variables
- User input
- If-else statements
- For loop
- Arithmetic operations
